# Architecture & Specifications

EnvOS uses a **Tri-Tier Decoupled Architecture**. It cleanly splits concerns between presentation, metadata orchestration, and computational execution across three distinct physical entities.

## 2. Structural Layer Breakdown

### Layer 1: Client Presentation Tier (Thin Client)
* **Execution Boundary**: Client web browser (Chrome, Edge, Safari, Firefox).
* **Window Management**: Manages window state, viewport coordinates, minimize/maximize animations, and dynamic z-index stacking via `react-rnd`.
* **Code Canvas**: Renders code models with syntax engines, tabs, and line numbers using `@monaco-editor/react`. Automatically toggles `readOnly: true` when the client's role is `Viewer`.
* **Terminal Canvas**: Parses ANSI escape sequences and renders a hardware-accelerated text grid via `@xterm/xterm`. Resizes dynamically using `@xterm/addon-fit`.
* **Key Event Interception**: Intercepts browser shortcuts (e.g., `Ctrl + C`, `Ctrl + W`) and converts them into raw terminal escape sequences (`\x03`, `\x17`) to prevent accidental browser tab closures or navigation traps.
* **Storage Footprint**: **0 MB** on the client device. All data is retrieved on-demand and retained in component memory.

### Layer 2: Cloud Control Plane (Supabase)
* **Execution Boundary**: Supabase Managed Cloud Infrastructure.
* **Identity Verification**: Validates user credentials, issues signed JWTs, and manages user state through GoTrue.
* **Relational Metastore**: Stores persistent records for `profiles`, `workspaces`, and `workspace_members`.
* **Authorization Guard**: Enforces database-level Row-Level Security (RLS) policies to prevent unauthorized queries from manipulating workspace properties or member roles.
* **Data Flow Constraint**: Strictly limited to low-frequency operations (sign-in, workspace registration, metadata reads). **Never processes streaming terminal I/O.**

### Layer 3: Compute Plane Runner Node (Laptop 2)
* **Execution Boundary**: Native Linux daemon or WSL2 (Ubuntu) process running on dedicated host hardware.
* **Shell Isolation via `node-pty`**: Spawns native pseudo-terminal devices (`/dev/pts`) running `/bin/bash` with their Current Working Directory (`cwd`) locked to the allocated workspace directory.
* **File System Operations**: Directly executes disk reads, writes, and tree generations via Node's native `fs` module. Watches file modifications using `chokidar` and broadcasts `files:changed` alerts.
* **In-Memory Session Store**: Maintains a volatile mapping of active workspaces:

```typescript
interface ActiveSession {
  roomCode: string;
  cwd: string;
  ptyProcess: IPty;
  scrollback: string; // Rolling 64 KB ANSI buffer
  members: Map<string, { userId: string; role: 'Host' | 'Editor' | 'Viewer' }>;
  teardownTimer: NodeJS.Timeout | null;
}
```

* **Packet Filtering**: Intercepts incoming WebSocket messages, checks the client's role, and drops unauthorized input before it reaches the bash process.

## 3. Communication Networks & Protocol Specifications

EnvOS uses two distinct communication patterns depending on data frequency:

| Channel | Protocol | Handshake / Target | Payload Type |
| :--- | :--- | :--- | :--- |
| **Auth & Metadata** | HTTPS REST | Supabase Cloud API | JSON Web Tokens, Schemas |
| **Filesystem CRUD** | HTTP REST | Laptop 2 (Express Server) | File buffers, Tree JSON |
| **Terminal Input** | WebSocket (WSS) | Laptop 2 (Socket.io) | Keystrokes, Break Bytes |
| **Terminal Output** | WebSocket (WSS) | Laptop 2 (Socket.io) | ANSI Stream Strings |
| **File Watcher** | WebSocket (WSS) | Laptop 2 (Socket.io) | Tree Invalidation Signals |

### Network Traversal Strategies

* **Option A: Cloudflare Zero-Trust Tunnel (Public / Campus Network)**  
  Laptop 2 initiates an outbound HTTPS connection to Cloudflare edge nodes via `cloudflared`. Edge nodes assign a public domain (`https://runner.trycloudflare.com`). Clients connect to this domain, bypassing client-isolation firewalls on university Wi-Fi, eliminating NAT routing, and delivering built-in SSL/TLS termination.
* **Option B: Local Area Network (Offline / Private Hotspot)**  
  Laptop 2 binds the Express daemon to `0.0.0.0:5000`. Clients on the same network connect directly to Laptop 2's local IPv4 address (`http://192.168.1.45:5000`). Latency remains sub-5ms with zero external internet dependencies.

## 5. Security & Boundary Defenses

### Path Traversal Protection (Jail Barrier)
Every disk request (read, write, delete) is checked to prevent traversal attacks (`../../`):

```javascript
const safePath = path.resolve(session.cwd, path.normalize(requestedPath));
if (!safePath.startsWith(path.resolve(session.cwd))) {
  return res.status(403).json({ error: 'Access denied: Directory traversal blocked.' });
}
```

### Role Verification at the Socket Level
Security rules are not enforced solely through UI constraints. If a client alters client-side code to bypass a `readOnly` flag, the server checks the client's role stored in memory and discards unauthorized operations immediately.

### Execution Sandboxing Scope (MVP)
In this MVP, `node-pty` processes run under an unprivileged Linux service account in WSL2. The process has no passwordless `sudo` privileges, restricting operations to the user space and preventing changes to the underlying host OS.

## 6. Failure Modes & Edge-Case Mitigations

| Boundary Condition | Root Failure Cause | Architectural Mitigation |
| :--- | :--- | :--- |
| **Windows Toolchain Breakage** | Missing C++ compilers for `node-pty` bindings | Execute `server/` exclusively within WSL2 (Ubuntu) on Laptop 2. |
| **Campus Wi-Fi Isolation** | Enterprise routers block peer-to-peer LAN sockets | Route traffic through an outbound Cloudflare Tunnel (`cloudflared`). |
| **ANSI Text Overlap** | Client canvas dimensions differ from virtual PTY | Run `fitAddon.fit()` and emit `terminal:resize` events on window change. |
| **Terminal Desync on Reconnect** | New WebSocket connections miss previous output | Buffer output in a 64 KB circular scrollback cache on the server. |
| **File Tree Desync** | Shell operations run independently of React state | Watch workspace folder using `chokidar` and emit `files:changed`. |
| **Main-Thread Canvas Freezing** | Infinite loops output millions of bytes per second | Buffer and throttle terminal output to 16ms intervals (~60 FPS). |
