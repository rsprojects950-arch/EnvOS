# Welcome to EnvOS 🪐

**EnvOS** is a browser-native Collaborative Cloud Operating System and Virtual Development Workspace.

Instead of opening a standard website or a traditional single-page code editor, the user opens a browser tab and is greeted with a full desktop operating system experience:

- **Interactive Desktop Canvas**: Custom wallpapers, ambient lighting, and window management.
- **macOS-Style Dock**: Smooth floating application launcher at the bottom of the screen.
- **Windowing System**: Draggable, resizable, floating windows with Apple-style traffic light controls.
- **Code Studio**: Monaco/VS Code-powered code editor with multi-file tabs and syntax highlighting.
- **Cloud Shell**: Ultra-responsive terminal session powered by real pseudo-terminals (`node-pty`) and `xterm.js`.
- **Real-Time Collaboration**: Multi-user rooms accessible via 6-character room codes with role-based access control.
